# EcoBala — образовательная eco-платформа для школьников Казахстана

Прототип современной веб-платформы EcoBala с игровыми механиками и экологическими задачами.

## Что реализовано

- Лендинг с акцентом на ценность проекта для детей 7–17 лет.
- Личный кабинет ученика: задания, баллы, награды и виртуальная валюта.
- Панель школы и директора: школьный рейтинг и KPI по экодостижениям.
- Городской уровень: карта активности и рейтинг городов.
- Игровой блок: эко-головоломки и интерактивный сценарий по экономии воды.

## Запуск

Откройте `index.html` в браузере

или запустите локальный сервер:

```bash
python -m http.server 4173
```

и откройте http://localhost:4173
